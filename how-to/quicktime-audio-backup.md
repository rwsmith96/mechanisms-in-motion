# How to run a QuickTime audio backup

**What it is:** a free, dead-simple recording of your own microphone on your own computer, running quietly in the background during every session. It is insurance. The main recording lives in Riverside; if Riverside ever loses or corrupts your track, this local file saves the episode. Each host backs up their *own* voice.

**When:** every recording, started right before you hit Record in Riverside, stopped after the session ends.

## On a Mac (QuickTime Player, already installed)

1. Open **QuickTime Player** (Cmd+Space, type "QuickTime", Enter).
2. Top menu: **File > New Audio Recording.** A small recorder window appears.
3. Click the small **chevron (˅) next to the round red button** and choose your **Shure MV7+** as the microphone (not "MacBook Microphone").
4. Click the **red Record button** right before the session starts. Leave it running the whole time.
5. When the session is over, click **Stop** (the same button).
6. **File > Save**, name it `MiM-EpNN-yourname-backup` (for example `MiM-Ep03-carla-backup`), and save it into that episode's folder.

That's it. You never look at it again unless something went wrong with the main recording.

## On Windows (Voice Recorder, already installed)

1. Open the **Voice Recorder** (or "Sound Recorder") app from the Start menu.
2. In its settings, set the input device to your **Shure MV7+**.
3. Press the **record** button before the session, **stop** after, and rename the file `MiM-EpNN-yourname-backup`.

## Notes

- It only records *your* mic. That's the point: Rich backs up Rich, Carla backs up Carla.
- It uses almost no computer power. You can record in Riverside and QuickTime at the same time with no problem.
- If you forget to stop it, no harm; just stop and save when you remember.
