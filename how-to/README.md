# How-to guides

Short, plain-language guides for every hands-on step of running Mechanisms in Motion. Each one decodes the jargon and ends with a prompt you can paste straight into Claude or ChatGPT if you get stuck. No technical background needed.

Start with the [six-pager roadmap](../mim-podcast-roadmap.pdf) for the big picture and [CARLA-START-HERE](../CARLA-START-HERE.md) for first-time setup. Then use these as you go:

| Guide | Use it when |
|---|---|
| [import-calendar](import-calendar.md) | You're setting up: download and import the project calendar. |
| [hardware-setup](hardware-setup.md) | Your kit arrived: assemble and test the mic, camera, light, headphones. |
| [day1-setup](day1-setup.md) | One-time setup of the four accounts (Riverside, Descript, Transistor, Calendly). |
| [riverside-record](riverside-record.md) | It's a recording day: join, set up, record, and protect the files. |
| [quicktime-audio-backup](quicktime-audio-backup.md) | Every recording: run the free local backup of your own mic. |
| [descript-edit](descript-edit.md) | After recording: turn the raw files into a finished episode. |
| [export-settings](export-settings.md) | What all those numbers (LUFS, 1080p, etc.) mean, in plain English. |
| [publish-and-qa](publish-and-qa.md) | Episode's edited: the quality check and how to publish it. |

**Roles:** Rich owns logistics (tools, gear, editing, publishing). Carla owns the guest slate (who comes on, outreach, the question arc). Both co-host every recording.
