# How to import the project calendar

The project runs off one calendar file: **mim-recording-schedule.ics**. An ".ics" file is just a standard calendar file that any calendar app can read. Import it once and every step of the launch, the prep deadlines, the recording sessions, the publish reminders, appears in your own calendar, each with instructions in its notes.

**Download it here:** [mim-recording-schedule.ics](https://raw.githubusercontent.com/rwsmith96/mechanisms-in-motion/main/mim-recording-schedule.ics) (your browser may show text; use right-click > "Save Link As" to download the file).

## Import it

**Google Calendar (on a computer):**
1. Open Google Calendar.
2. Click the **gear icon > Settings.**
3. Left menu: **Import & Export > Import.**
4. Choose the downloaded `mim-recording-schedule.ics` file, pick which calendar to add it to, and click **Import.**

**Apple Calendar (Mac or iPhone):**
1. Open the downloaded `.ics` file (double-click on Mac, or tap on iPhone).
2. Calendar asks which calendar to add the events to. Confirm.

**Outlook:**
1. **File > Open & Export > Import/Export.**
2. Choose **Import an iCalendar (.ics) file** and select the file.

## How to use it

Open any event (for example "MiM: Record Ep01"). In its notes you'll find three things: **what to do**, **what "right" looks like** (how to know it's done), and a **ready-to-paste prompt** you can copy into Claude or ChatGPT to be walked through the step. Some steps also link to a short how-to guide.

If a date changes, Rich updates the file and re-sends it; import the new one the same way.
